2. Guia de Uso: Sistema de Controle de Pagamentos (Kleber)

O Diretor Financeiro acessa o sistema via link na Área Administrativa (acessarControlePagamentos()).

Estrutura e Segurança

  • Senha de Registro: É **obrigatória** para lançar pagamentos ou incluir novos membros no sistema.
  • Base de Dados: O sistema depende de três abas principais: **CADASTRO**, **VALORES** e **CALENDARIO_PGTO_AAAA**. Mantenha-as precisas.

Fluxo de Trabalho

Gestão de Inadimplência Pendências Início do mês (para emissão de cobranças).

3. Guia de Manutenção Técnica (Waldeck e Nando)

Comandos essenciais para atualizar e proteger o site (Uso no PowerShell/Git Bash).

Comando Principal: Publicação (`push_to_git_v2.ps1`)

  • Função: Envia todas as alterações (códigos, textos, links) para o site online.
  • Ação: Após salvar as mudanças, rodar: .\push_to_git_v2.ps1
  • Mensagem: Sempre use uma mensagem de confirmação clara (Ex: "Atualizado Irmandade", "Corrigido Aniversariante").

Comando de Emergência: Restauração (`restore_state.sh`)

  • Função: **Volta o site no tempo** (desfaz a última alteração) se algo der errado (erro de código).
  • Uso: SOMENTE se o site quebrar ou apresentar erro.
  • Ação: Rodar o script: ./restore_state.sh
